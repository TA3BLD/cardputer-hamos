HamOS offline map data, made by tools/map/make_map.py.

lines0-2.bin   Coastlines and country borders at three levels of detail.
               Made with Natural Earth (public domain), via the npm package
               world-atlas 2.0.2.
cities0-2.bin  Places with 1000 or more inhabitants.
               Contains data from GeoNames (www.geonames.org), licensed under
               Creative Commons Attribution 4.0 (CC BY 4.0), via the npm
               package all-the-cities 3.1.0. Names were shortened to the
               letters HamOS can show.
